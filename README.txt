# Deep Learning Pipeline: Klasifikasi Anomali Infrastruktur

Repositori ini berisi studi kasus penerapan model *Deep Learning* untuk otomatisasi deteksi dan klasifikasi kondisi aset/infrastruktur (mengacu pada pemanfaatan *Machine Learning* dan otomatisasi analitik pada era industri modern[cite: 2, 3]).

## Fitur Utama
- **Neural Network Architecture**: Menggunakan arsitektur *Multilayer Perceptron* dengan lapisan *Dropout* untuk mencegah *overfitting*.
- **Class Weight Balancing**: Penyesuaian bobot kelas otomatis guna mengoptimalkan deteksi kelas minoritas (anomali/kerusakan).
- **Automated Prediction Pipeline**: Siap diintegrasikan ke dalam ekosistem analitik berbasis *cloud*[cite: 2, 3].
